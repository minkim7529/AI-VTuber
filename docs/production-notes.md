# 버전별 작업 기록

작업하면서 남긴 보고서와 수정 기록을 기준으로, 어떤 부분을 만들고 보정했는지 정리했습니다.

파츠 분리 도판과 목·얼굴 수정 전후 이미지를 포함한 상세 과정은 [파츠 분리부터 턱과 목 보정까지](rigging-retrospective.md)에 정리했습니다. [당시 보고서 5개](archive/README.md)도 함께 보관했습니다.

## 2026-09-27~28 — 초기 세일러복 모델

원본을 복사해 보존하고 파츠 분리와 PSD 제작부터 시작했습니다. 새 작업 폴더에 이전 산출물이 없어서 삭제할 파일은 없었습니다.

v009에서는 ArtMesh 33개, Parameter 17개, Deformer 11개와 2048×2048 텍스처 한 장으로 구성했습니다. Cubism FREE에서 프로젝트를 열고 SDK 4.2 형식으로 내보낸 뒤, VTube Studio 1.35.10에서 모의 입력으로 확인했습니다.

고개와 시선, 눈 개폐, 입 형태, 복합 동작을 확인했고 물리 입력 후 중립 상태로 돌아오는지도 검사했습니다. 이 단계에서는 실행 가능한 모델을 만드는 데 도달했지만, 얼굴 회전과 파츠 경계 등은 계속 손볼 부분으로 남겼습니다.

참고한 당시 기록: `clean_start.md`, `capability_report.md`, `final_report.md`.

## 2026-10-06 — BlueSailor V2 refined

세일러복 모델을 추가로 보정한 버전입니다. 최종 편집 원본은 r4이고, PSD도 37레이어로 갱신했습니다.

주로 수정한 부분은 다음과 같습니다.

- 눈이 반쯤 감길 때 열린 눈꺼풀과 감은 눈 선이 겹치는 부분
- 눈꼬리 바깥쪽의 잘린 듯한 경계
- 턱 끝의 회전 변형과 뒷머리 깊이
- 혀 모양과 혀를 내밀 때 남는 닫힌 입 선

검사 기록에는 ArtMesh 37개, Parameter 19개, Warp 18개, 2048 텍스처 한 장이 남아 있습니다. 눈과 회전 화면은 r3에서, 기본 입과 혀는 r4에서 확인했습니다. r4는 혀 파라미터가 0일 때 기존 상태를 유지하도록 수정했습니다.

놀람·웃음·경멸·울음·혀 내밀기 표정과 일회성 혀 모션도 유지했습니다. 최종 보정 후 iPhone 실기 검증은 아직 남아 있고, 큰 회전의 원화 경계와 표정 중복 처리도 개선할 부분입니다.

참고한 당시 기록: `BlueSailor_V2_refined_release/README.md`, `detail_validation.json`.

## 2026-10-11 — JerseyMaid JawTurn R1

메이드복 모델은 FaceCleanup R5를 바탕으로 턱과 목의 회전 연결을 더 다듬었습니다. 턱 끝의 추가 수평 이동을 약 15px에서 7px로 줄이고, 볼과 턱의 비대칭 변형, 목 윗부분의 추종을 조정했습니다.

당시 기록에서는 회전 윤곽 35개 키폼과 목 25개 키폼에 격자 뒤집힘이 없었고, VTube Studio XY 35조합의 API 응답과 5개 표정 호출을 확인했습니다. 설치한 MOC3와 내보낸 파일의 해시도 일치했습니다.

좌우 회전과 대각선 입 벌림, 눈 감기 화면을 확인했지만 모든 각도의 시각적 품질을 완성한 상태는 아닙니다. 이 버전도 최종 수정 후 iPhone 실기 검증은 남아 있습니다.

참고한 당시 기록: `BlueSailor_JerseyMaid_JawTurn_release/README.md`, `runtime_validation.json`.

## 프롬프트에 대해

[공개한 프롬프트](../prompts/live2d-vtuber-production-prompt.md)는 처음 세일러복 상반신 모델 제작에 사용했습니다. 메이드복 전신 의상과 후속 수정은 추가 요청을 거쳐 진행했기 때문에, 모든 결과가 이 프롬프트 한 번으로 만들어진 것은 아닙니다.

프롬프트에는 목표와 검수 기준을 담았고, 실제로 구현하고 확인한 범위는 위 작업 기록에 따로 정리했습니다.
