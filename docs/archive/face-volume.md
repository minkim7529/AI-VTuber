# Jersey Maid 얼굴 볼륨과 옆보기 보정

HairDetail을 기준으로 얼굴 전체를 좁히던 yaw 변형을 제거했습니다. 얼굴 외곽의 폭은 유지하면서 중앙 표면이 더 이동하도록 완만한 곡면 변형을 사용합니다. 가까운 쪽과 먼 쪽의 눈 영역 폭에 작은 차이가 생기며 코·입은 깊이에 따라 추가 이동합니다. 코 10px, 입 6px의 최대 추가 이동은 원화 로컬 좌표 기준입니다. 눈·얼굴·그림자·눈물은 공통 변형을 따라가며 혀는 입과 같은 깊이 변형을 따릅니다.

X축 7단계×Y축 5단계로 전환을 구성했습니다. 윤곽의 중복 변형을 제거했습니다. 바뀐 것은 FaceTurn, FaceContour, NoseDepth, MouthDepth 네 워프이며 37개 메시 키폼과 나머지 18개 워프는 동일합니다. 앞서 보강한 머리카락 물리, 눈/입 추적 감도, 목 색상과 몸통 리깅은 유지했습니다.

검증: Cubism SDK 4.2 출력 및 VTube Studio 로드, 정면/양방향 최대 옆보기, 대각선+눈 감기+입 벌림, 반대 대각선+혀를 확대 확인했습니다. 표정 5종·혀 복귀·호흡·머리카락/의상 물리도 검사했습니다. 130개 변경 워프 키폼 격자 방향을 확인했습니다. volume_geometry.json의 비율은 해석식의 샘플 지점 비교이며 실제 화면 실측값은 아닙니다. 같은 +30 입력의 전후 화면을 evidence/volume_comparison.jpg에 포함했습니다.

정면 원화 기반의 입체감 보정이며 완전한 측면 그림은 아닙니다. 귓볼 주변 잔여선과 일부 앞머리 끝의 밝은 테두리는 남아 있습니다. 합성 추적 입력으로 검사했으며 새로운 수정의 iPhone 실기 재확인은 아직입니다.

runtime/BlueSailor_JerseyMaid_Detail이 실행 폴더입니다. editable에 CMO3, 35레이어 PSD, 보존된 머리/의상 physics3.json을 제공합니다. CMO3 재출력 시 이 물리 설정을 유지하세요. PSD 통째 재가져오기는 기존 로컬 좌표 연결을 바꿀 수 있습니다. 이전 HairDetail 배포본은 보존했습니다.
