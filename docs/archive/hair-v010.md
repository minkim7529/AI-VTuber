# v010 머리카락 흔들림 개선 / 2026-09-28

앞머리·옆머리·뒷머리의 독립 물리에 연결된 변형 폭을 키웠습니다. 중립 키폼은 유지하고 뿌리에서 끝으로 점차 커지는 기존 변형을 보강했습니다.

- 앞머리: 끝부분 최대 약 7.2px (기존 1.8px).
- 옆머리: 최대 약 20.4px (기존 12px).
- 뒷머리: 최대 약 14px (기존 8px).

위 수치는 모델 좌표에서 파라미터 ±1의 최대 격자 변위이며, 항상 이 크기로 흔들리는 것이 아닙니다. 화면 크기와 실제 물리 출력에 따라 달라집니다. 물리 그룹별 반응 속도·감쇠와 리본 설정은 유지했습니다.

Cubism 5.3 FREE에서 새 CMO3를 열고 SDK 4.2로 실제 내보냈습니다. VTube Studio에 설치하고 로드했습니다. 모의 얼굴 입력 12초 + 중립 12초로 재검증했습니다. 출력 최대 절댓값은 앞머리 0.579, 옆머리 0.510, 뒷머리 0.476이며 끝에 세 값 모두 0으로 복귀했습니다. ±1 포화는 없었습니다.

양방향 고개 기울기, 눈감기 조합과 중립 복귀 화면을 확인했습니다. 3장 화면과 API 기록은 evidence에 있습니다. iPhone Face ID 실기 시험이 아닌 로컬 API 모의 입력 시험입니다.

FREE 사용량은 메시 33, 파라미터 17, 디포머 11, Parts 1, 2048 텍스처 한 장으로 유지됩니다. 원본 그림·PSD는 변경하지 않았습니다.

물리 JSON은 runtime/BlueSailor_Clean_20260927/BlueSailor.physics3.json입니다. Cubism 프로젝트 안의 물리 편집 설정과는 별도이므로 재내보내기 때 model3의 Physics 참조를 유지해야 합니다.

기존 반감기 눈 경계와 Head X/Y의 약한 입체감, iPhone 실기 미검증 한계는 남아 있습니다. 머리카락 개선으로 전체 모델의 최종 원화 품질까지 완료됐다는 의미는 아닙니다. 기존 기능 검증과 제한은 baseline_report_v009.md에 기록했습니다.
