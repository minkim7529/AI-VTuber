# Jersey Maid 목 연결 수정본

기존 BlueSailor_JerseyMaid_Detail 모델에 적용했습니다. 이전 Detail 배포 ZIP과 V1/V2 보관본은 유지했습니다.

원인: 상체 텍스처에 생성 시안의 턱선과 머리카락이 남아 있었고, 목 피부가 옷깃과 한 파츠여서 얼굴 회전과 연결되지 않았습니다.

- 잔여 턱/머리 그림을 제거했습니다.
- Neck_Bridge 파츠를 추가하고 목 피부를 옷깃에서 분리했습니다.
- 목 아래쪽은 옷깃에 고정하고 위쪽은 얼굴 X/Y 회전과 Z 기울기를 따라가도록 연결했습니다.
- 기존 얼굴·머리 26개 메시의 키폼과 표정, 눈 추적 보정, 혀, 머리카락/의상 물리 설정은 유지했습니다.

runtime/BlueSailor_JerseyMaid_Detail은 VTube Studio 실행 폴더입니다. editable에는 수정 CMO3와 35레이어 PSD가 있습니다. PSD는 파츠 편집용이며 기존 CMO3에 통째로 재가져오면 좌표 연결이 달라질 수 있습니다.

Cubism FREE SDK 4.2 출력 및 VTS 로드, 중립·기울임·양방향 복합 회전과 엇갈린 회전에서 목 연결을 확인했습니다. 표정 5개, 혀 일회성 모션, 호흡과 8개 물리 그룹의 동작 검사를 통과했습니다. 테스트 입력은 종료하고 정상 추적으로 복귀했습니다. iPhone 실기 재검증은 아직 하지 않았습니다.

23개 파라미터, 22개 워프, 35개 실행 메시, 2048 텍스처입니다. 네이티브에는 비활성 옛 의상 메시 2개가 남아 있습니다. 정면 기반 모델의 기존 회전 범위에서 수정했으며 완전한 옆모습을 추가한 것은 아닙니다.
