# v011 iPhone 입력 보정

사용자가 iPhone 실기에서 눈이 반쯤 열리고 머리카락 흔들림이 보이지 않는 문제를 보고했습니다. 2026-09-28 실제 연결을 사용자에게 확인받고, 모의 입력 없이 VTS 입력/출력을 측정했습니다.

눈: EyeOpenLeft/Right 입력 범위를 0.05~0.45, 출력 범위를 0~1로 변경했습니다. smoothing은 3입니다. 실제 측정 입력 중앙값 약 0.58에서 출력 1, 깜빡임 중 출력 약 0.0003을 확인했습니다. 이 수치는 사용자별 보정값이며 모든 사람에게 같은 값이 맞지는 않습니다.

머리카락: 물리는 원래 켜져 있었으나 기존 출력이 작은 움직임에서 약 0.02로 미미했습니다. 앞/옆/뒤 출력 Scale을 각각 2.0/1.8/1.6으로 올렸습니다. 실제 iPhone 고개 움직임에 출력이 변하는 것을 확인했습니다. 큰 동작에서는 ±1 클램프에 도달하며, 모든 동작에서 비포화라는 주장은 하지 않습니다. 최종 체감에 대한 사용자 확인은 아직 받지 못했습니다.

파츠·메시·CMO3는 v010과 동일합니다. 최신 편집 파일은 editable/BlueSailor_Clean_v010.cmo3이며, 이번 변경은 VTS 매핑과 별도 물리 JSON에 있습니다. iPhone 연결 실시간 검증을 수행했으므로 과거 문서의 '실기 미검증'은 v010 이전 이력입니다. 장시간 안정성이나 모든 추적 동작을 검증한 것은 아닙니다.

기존 눈 경계와 Head X/Y 원화 품질 제한은 남아 있습니다. evidence/v011_live_summary.json은 이번 실측 요약이며 기존 v010 증빙과 구분합니다.
