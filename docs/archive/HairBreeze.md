# Jersey Maid 머리카락 살랑임 보강

FaceVolume의 얼굴 입체감 보정을 유지하고 앞머리·옆머리·뒷머리에 각각 머리끝 전용 워프를 추가했습니다. 추가 워프 3개, 키폼 75개입니다. 기존 22개 워프와 37개 메시 키폼은 그대로이며 머리 메시 6개의 부모를 새 끝부분 변형에 연결했습니다. 총 25개 워프, 23개 파라미터, 실행 메시 35개입니다.

머리끝이 다른 구역의 물리 입력을 조금 늦게 따라오도록 연결하고, 좌우에 작은 차이를 주었습니다. 머리 물리는 3단 진자이며 앞머리가 빠르게, 옆머리와 뒷머리가 더 느리게 반응합니다. 호흡을 약하게 섞어 정지 상태에서도 가벼운 움직임이 이어집니다. 이는 일정한 실제 바람 시뮬레이션이나 iPhone 호흡 추적이 아니라 모델의 자동 호흡에 연동된 보조 움직임입니다.

Cubism SDK 4.2 출력 및 VTube Studio 로드, 새 75개 키폼 격자 방향, 작은/빠른 회전과 정지 구간의 물리 출력, 양쪽 대각선 회전 경계, 표정·혀 복귀·호흡·의상 물리를 검사했습니다. 실제 측정은 evidence/hair_dynamics_final.json, 화면은 breeze_preview.jpg에 있습니다. 합성 입력 검사이며 iPhone 실기 재확인은 아직입니다.

얼굴 입체감, 눈과 입 감도, 목 색상, 몸통 리깅은 유지했습니다. 기존 귓볼 주변 잔여선과 일부 앞머리 끝 밝은 테두리는 남아 있습니다. 머리카락 한 올씩 분리한 원화는 아니며 기존 머리 파츠의 변형을 보강한 모델입니다.

runtime/BlueSailor_JerseyMaid_Detail이 실행 폴더입니다. editable에 CMO3, 최종 physics3.json과 35레이어 PSD가 있습니다. CMO3를 다시 출력할 때 제공 physics3.json을 유지하세요. PSD 통째 재가져오기는 기존 좌표 연결을 바꿀 수 있습니다. 이전 FaceVolume 배포본은 보존했습니다.
