# 혀 위치와 입 벌림 연결 보정

혀 내밀기 파츠가 입보다 위에서 시작하던 위치를 아래로 보정했습니다. 기존 원화 좌표 기준 7px 아래로 이동하고 입 벌림에 따라 최대 14px를 추가로 내려, 혀 뿌리가 입 안쪽에 연결되도록 했습니다. 혀 5단계×입 벌림 5단계, 총 25개 키폼을 사용합니다.

BodyMotion의 얼굴/몸통 리깅을 기준으로 tongue_out 메시만 변경했습니다. 나머지 36개 메시 키폼은 동일합니다. 사용자가 iPhone에서 자연스럽다고 확인한 MouthResponse 입 감도(입력 0.012~0.60, Smoothing 2)를 유지했습니다.

Cubism SDK 4.2 출력과 VTS 로드, 닫힌 입/중간 벌림/최대 벌림 및 양방향 회전의 혀 위치를 합성 입력으로 확대 검사했습니다. 혀 내밀기와 복귀, 기존 표정과 물리 검사도 통과했습니다. 새 혀 위치의 iPhone 사용자 확인은 아직입니다.

runtime은 실행용이며 editable에는 CMO3와 35레이어 PSD가 있습니다. evidence에 실제 검사 화면을 포함했습니다. PSD를 CMO3에 통째로 재가져오면 로컬 리깅 좌표 연결이 바뀔 수 있습니다.
