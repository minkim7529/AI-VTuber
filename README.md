# AI VTuber — AI와 함께 만든 Live2D 리깅 기록

정면 캐릭터 이미지에서 시작해 **AI 에이전트와 함께 파츠 분리, PSD 제작, Live2D 리깅, VTube Studio 실행 검증까지 진행한 프로젝트**입니다. Codex에 제작 조건과 검수 기준을 담은 긴 프롬프트를 전달하고, 실제 결과를 확인하며 여러 버전으로 수정했습니다.

이 저장소에는 제작 과정, Cubism 작업 화면, 실제 사용한 프롬프트를 공개합니다. 현재 공개 범위는 문서와 캡처이며, CMO3·PSD·실행 모델을 내려받는 배포 저장소는 아닙니다.

## 어떻게 진행했나

### 1. 제작 목표와 검수 기준을 프롬프트로 전달

원본 캐릭터의 인상을 유지하면서 눈 깜빡임, 입 개폐와 형태 변화, 시선, 머리 회전, 몸통·호흡, 머리카락·리본 물리를 구현하는 것을 목표로 삼았습니다. 사용 환경은 Cubism FREE와 VTube Studio, 최종 추적 목표는 iPhone Face ID였습니다.

프롬프트에는 작업 순서뿐 아니라 실패 기준도 넣었습니다. 예를 들어 감은 눈에서 홍채가 보이거나, 회전할 때 목이 떨어지거나, 입을 닫았는데 내부가 노출되면 다시 수정하도록 했습니다. 다만 프롬프트의 모든 요구가 완성됐다는 뜻은 아닙니다.

### 2. 원본을 보호하고 새 작업 폴더 구성

초기 작업 기록에서는 원본을 복사해 보존하고 해시를 확인했습니다. 새 작업 폴더에 이전 산출물이 없어 실제 삭제한 파일은 0개였습니다. 원본, 파츠, PSD, Cubism 프로젝트, 실행 모델, 검증 자료를 나누어 저장했습니다.

### 3. 한 장의 그림을 움직일 수 있는 파츠로 분리

얼굴, 눈 흰자와 홍채, 속눈썹, 입 선과 내부, 앞·옆·뒷머리, 목, 몸통, 소매, 세일러 칼라, 리본 등을 나누었습니다. 가려진 영역은 보완하고, 파츠를 다시 합성해 원본과 비교했습니다.

기록상 Python으로 이미지와 PSD를 생성·재개방했고, 숨은 뒷머리 보완에는 이미지 생성도 사용했습니다. 초기 검증본은 33개 파츠/PSD 레이어였고, 이후 V2 보정 계열은 37개 ArtMesh와 갱신된 37레이어 PSD로 확장됐습니다.

### 4. Cubism에서 파라미터와 변형 구조 연결

`ParamEyeLOpen` / `ParamEyeROpen`으로 좌우 눈 개폐를 분리하고, `ParamEyeBallX` / `ParamEyeBallY`로 시선을 연결했습니다. 입은 `ParamMouthOpenY`와 `ParamMouthForm`을 조합했습니다.

머리에는 `ParamAngleX/Y/Z`, 몸에는 `ParamBodyAngleX/Y/Z`와 `ParamBreath`를 사용했습니다. 실제 화면에서 `HeadXY`, `HeadZ`, `FaceTurn`, `FaceContour`, `HairBack`, `MouthDepth` 등의 계층을 확인할 수 있습니다. 머리카락과 리본에는 별도의 물리 그룹을 구성했습니다.

### 5. 실행 모델을 내보내고 VTube Studio에서 확인

CMO3 편집 원본과 함께 MOC3, 모델 참조 JSON, 물리 설정, 텍스처를 구성했습니다. 초기 작업에서는 SDK 5.3 출력과 설치된 VTube Studio Core 사이의 호환 문제가 있어 SDK 4.2로 다시 내보낸 뒤 로드를 확인했습니다.

VTube Studio GUI와 로컬 API로 모델을 불러오고, 모의 입력으로 눈·입·시선·회전·물리 동작을 검사했습니다. 이후 놀람, 웃음, 경멸, 울음, 혀 내밀기 등 표정과 일회성 혀 모션도 추가했습니다.

### 6. 화면을 보고 반복 보정

세일러복 V2에서는 반쯤 감은 눈의 선 겹침, 눈꼬리 경계, 턱 회전과 뒷머리 깊이, 혀 모양과 닫힌 입 선을 보정했습니다. 메이드복 버전은 얼굴·목·머리카락을 여러 차례 다듬고, 마지막 JawTurn R1에서 턱 끝의 과도한 수평 이동과 목의 회전 추종을 줄이거나 조정했습니다.

작업은 한 번의 생성으로 끝나지 않았습니다. **제작 → 저장 → 미리보기 → 문제 확인 → 수정 → 재검증**을 반복하는 방식이었습니다.

## AI와 사람의 역할

- **사용자:** 원본과 제작 프롬프트 제공, 원하는 외형과 수정 방향 전달, 결과 확인.
- **AI 에이전트:** 환경·공식 자료 확인, 파츠와 PSD 처리, 리깅 구조 및 파일 작업, Cubism/VTube Studio 조작과 검사, 반복 수정 및 기록 작성.
- **작업 도구:** Codex, Python 이미지·PSD 처리, Live2D Cubism FREE, VTube Studio GUI/API. iPhone Face ID는 목표 추적 환경입니다.

## 현재 확인된 범위와 남은 점

두 모델의 편집 원본이 Cubism에서 열리는 것은 이번 캡처 작업에서 직접 확인했습니다. 과거 작업 기록에는 VTube Studio 로드, 합성 파라미터 입력, 표정 호출, 파일 참조 검사와 일부 극단 조합 검사가 남아 있습니다.

- 큰 회전에서 턱·목과 원화 경계가 드러나는 문제는 추가 개선 대상입니다. 정면 원화에서 만든 제한적인 2.5D 리깅이며, 완전한 측면 원화를 갖춘 모델은 아닙니다.
- A/E/I/O/U 계열은 입 파라미터의 형태 조합입니다. 음성을 인식해 음소를 자동 선택하는 시스템은 아닙니다.
- 초기 v011에는 iPhone 입력 보정 기록이 있으나, 여기 소개한 **V2 refined와 JerseyMaid JawTurn 최종 보정 후의 iPhone 실기 검증은 완료로 기록돼 있지 않습니다.**
- 메이드복 JawTurn 기록에는 회전 윤곽 35개·목 25개 키폼의 격자 뒤집힘 검사와 XY 35조합 API 검사가 있습니다. 이것이 모든 자세의 시각적 완성도를 보장하지는 않습니다.
